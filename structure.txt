Какая архитектура должна получиться
API-ключ остаётся только на сервере.
Frontend вообще не должен знать.

                FlightSearch.vue
                       │
                       │ пользователь вводит
                       ▼
              Madrid / Barcelona
                       │
                       │ выбирает вариант
                       ▼
                  MAD / BCN
                       │
                       │ Search
                       ▼
          store.dispatch('tickets/fetchTickets')
                       │
                       ▼
                 Vuex tickets
                       │
                       ▼
                axios /tickets
                       │
                       ▼
                 Vite proxy
                       │
                       ▼
               Express server
                       │
                       │ добавляет API key
                       ▼
             Travelpayouts API
                       │
                       ▼
                 response.data
                       │
                       ▼
                 Vuex state.tickets
                       │
                       ▼
               TicketsList.vue
                       │
                       ▼
                  карточки билетов

У тебя уже есть Express.
Поэтому лучше сохранить ту же архитектуру:

FlightSearch.vue
       │
       ▼
Vuex
       │
       ▼
Express
       │
       ▼
Travelpayouts Autocomplete API

а не:

Vue
 │
 └──────► Travelpayouts
Потому что мы уже строим приложение через backend-прокси.
